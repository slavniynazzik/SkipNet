# Changelog

Краткая сводка каждого обновления. Раздел с номером версии автоматически
попадает в описание GitHub-релиза при публикации тега (`release.yml`).

## 1.0.2

Исправления стабильности, сохранности настроек и безопасности обновлений.

- Конфиг записывается атомарно; при сбое подхватывается `.backup`, настройки больше не теряются.
- Очередь записи конфига восстанавливается после ошибки; автозапуск и трей применяются в правильном порядке.
- Установщик SkipNet, `TgWsProxy` и архив Zapret проверяются по SHA-256 и размеру перед запуском/установкой.
- Если установщик не удалось запустить, приложение остаётся открытым и показывает ошибку.
- Бандл Zapret распаковывается в staging-каталог и заменяется атомарно — старый бандл не пропадает при сбое.
- Пользовательские записи списков сохраняются в `list-general-user.txt` и не удаляются при обновлении списков.
- Исправлен статус фатальной ошибки WinDivert, который перезаписывался событием выхода процесса.
- Маркеры обновления очищаются после установки; ручное удаление снова удаляет все данные.
- UI обновляется после изменений конфига из main-процесса; исправлены откат версии Zapret, ложный успех «Перезагрузить процессы», поле порта и иконка maximize.
