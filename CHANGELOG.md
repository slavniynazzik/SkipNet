# Changelog

Краткая сводка каждого обновления. Раздел с номером версии автоматически
попадает в описание GitHub-релиза при публикации тега (`release.yml`).

## 1.6.2

В каталог hosts добавлен пресет **«Roblox (обложки)»**: адреса `tr.rbxcdn.com`
прописываются в hosts, если провайдер подменяет DNS и обложки игр не загружаются.

### Добавлено

- **Roblox (обложки).** Новый сервис в разделе «Напрямую» на странице **Hosts**:
  7 проверенных IPv4-адресов CDN для `tr.rbxcdn.com`. Включается обычным
  переключателем, как остальные сервисы.
- **Проверка адресов.** Перед записью SkipNet проверяет доступность каждого IP по
  TCP 443 и пропускает неотвечающие. Кнопка **«Проверить адреса»** перезапрашивает
  актуальные адреса через DoH и сама обновляет пресет — это надёжнее, чем
  держать один статичный список.
- **DNS-кэш.** После применения SkipNet сбрасывает DNS-кэш автоматически,
  отдельно запускать `ipconfig /flushdns` не нужно.

### Если обложки снова пропали

Адреса CDN периодически меняются. Откройте **Hosts → Roblox (обложки)** и
нажмите «Проверить адреса». Для ручной проверки:
`nslookup tr.rbxcdn.com 9.9.9.9`.

## 1.6.1

Исправление счётчиков в карточке «Список хостов и IP»: теперь они всегда
показывают реальные числа, обновляются после загрузки списков и объясняют,
почему IP-диапазоны могут не применяться.

### Исправлено

- **Один источник чисел.** Заголовок карточки считал только `list-general.txt`,
  а блок обновления — сумму четырёх файлов, поэтому одновременно показывались
  разные значения. Теперь и заголовок, и блок обновления берут числа из общего
  снимка: хосты (все управляемые файлы) и IP-диапазоны.
- **Счётчик IP больше не «замирает» на единице.** При режиме IPSet «Отключён»
  или «Все IP» скачанный список сохраняется в `ipset-all.txt.backup`, а активный
  файл остаётся заглушкой. Карточка теперь показывает число диапазонов в
  резервной копии, текущий режим и кнопку **«Включить „По списку“»**, которая
  переносит скачанные диапазоны в активный файл.
- **Видно результат обновления.** Уведомление после загрузки показывает
  изменение счётчиков (`хосты 221 → 221 · IP 1 → 1`) и отдельно сообщает, если
  IP-список сохранён в резервную копию. Если содержимое upstream не изменилось,
  это тоже видно по одинаковым числам.
- **Счётчики перечитываются при раскрытии карточки**, поэтому изменения режима
  IPSet в сетевой карточке и правки файлов вручную больше не оставляют старые
  значения на экране.

## 1.6.0

Тестирование стратегий теперь выполняется внутри SkipNet по той же методике, что
и встроенный `utils\test zapret.ps1` — пункт «12. Run Tests» в `service.bat`.

### Новое

- **Родные проверки Zapret в интерфейсе.** Цели читаются из `utils\targets.txt`
  (16 адресов: Discord, YouTube, Google, Cloudflare и публичные DNS). Каждый URL
  проверяется `curl.exe` в режимах HTTP/1.1, TLS 1.2 и TLS 1.3, затем каждая цель
  пингуется с таймаутом 1 с. Классификация `OK` / `ERROR` / `UNSUP` / `SSL`
  повторяет консольный отчёт.
- **Аналитика как в `service.bat`.** У стратегии видны счётчики
  `HTTP OK / ERR / UNSUP` и `ping OK / Fail`; «лучшая» выбирается по числу
  HTTP OK, при равенстве — по ping OK.
- **Подробности по целям.** Список проверок раскрывается рядом со стратегией:
  статус каждого TLS-режима, время пинга или таймаут.
- **Отмена и восстановление.** Тест по-прежнему можно прервать: `winws.exe`
  останавливается, прежняя стратегия и режим ipset возвращаются, частичный отчёт
  сохраняется.
- **Меньше лишнего.** Старый «собственный» HEAD-опрос заменён родными проверками;
  результаты прежнего движка не применяются к новой версии.

### Ограничения

- DPI-проверки TCP 16–20 и выбор отдельных конфигов остаются в резервном запуске
  **Обслуживание → Тесты в консоли** (родной скрипт в отдельном окне).
- Один прогон занимает примерно 2–4 минуты и требует `curl.exe` из System32
  (есть в Windows 10/11 по умолчанию).

## 1.5.1

Интерфейс: выключенные переключатели больше не выглядят ошибкой, секрет
Telegram скрыт, а тест Zapret не запускается сам.

### Интерфейс

- **Выключенный переключатель выглядит выключенным.** Красный градиент,
  который раньше означал «выключено», читался как ошибка; теперь у трека
  нейтральный фон, серая «горошина» и обычная рамка. Включённые переключатели
  сохранили зелёный градиент.
- **Секрет Telegram скрыт по умолчанию.** В ссылке `tg://proxy?...&secret=…`
  значение секрета заменяется точками, а поле «Секретный ключ» показывается
  как пароль. Кнопка с глазом раскрывает значение, кнопка «копировать»
  по-прежнему копирует полную ссылку. Порт принимает 1024–65535: без прав
  администратора TgWsProxy не может занять привилегированный порт.
- **Zapret больше не запускает тест стратегий при открытии вкладки.** Перебор
  запускается только кнопкой «Запустить тест» — страница не блокирует тумблер
  и не нагружает сеть без запроса пользователя.
- **Русские склонения.** Счётчики hosts, домены сервисов, фейки, IPSet и тосты
  обновления списков теперь пишут «21 файл», «31 сервис», «60 записей» вместо
  «21 файла» и «31 сервисов».
- **Пустые логи и поиск.** На вкладке «Логи» при отсутствии записей появилась
  подсказка вместо пустого экрана; в hosts поле поиска растягивается на
  свободное место и не переносится при ширине окна 1000 px.

## 1.5.0

Аудит безопасности: обновления ставятся только с проверенной контрольной суммой,
а приложение с правами администратора запускает только собственные бинарники.

### Безопасность

- **Проверка обновлений больше не «падает в открытую».** Пустой, неверный по
  формату или не совпавший по размеру/`sha256` дайджест блокирует установку;
  раньше отсутствие digest означало «проверку пропустить», и подменённый
  установщик запускался с правами администратора.
- **Метаданные только с `api.github.com`, суммы — напрямую.** Зеркала
  (`gh-proxy.com`, `ghfast.top`) остались только для скачивания проверенных
  ассетов и больше не могут подсунуть свой JSON с чужим digest; `SHA256SUMS`
  читается только из самого релиза.
- **Установка по тегу.** Main-процесс сам находит ассет разрешённого имени в
  последнем релизе, а рендерер больше не передаёт URL, digest и размер — его
  компрометация не превращается в Elevated RCE.
- **Админ-права только после проверки.** Временный установщик и staging
  создаются в admin-only каталоге, а elevated-процесс запускается только после
  сверки хеша файла, поэтому между проверкой и запуском подменить файл нельзя.
- **Preload отдаёт только allow-list каналов.** Сырой `ipcRenderer`, доступ к
  `process.env` и `webFrame` убраны, включён `sandbox: true`; вызов
  неразрешённого канала отклоняется.
- **IPC принимает вызовы только из своего окна.** Проверяется точный путь
  `out/renderer/index.html` (или dev-origin), а не любой `file://` и не любой
  `localhost:<port>`; навигация и `window.open` на сторонние адреса
  блокируются.
- **Схема конфига и защита от prototype pollution.** `deepMerge` обходит только
  собственные ключи и блокирует `__proto__`/`constructor`/`prototype`, а патч
  конфига проверяется по allow-list ключей, типам и диапазонам до записи.
- **Удалён запуск кода из user-writable мест.** Поле `tgws.binaryPath` больше
  не читается, бинарники всегда берутся из `resources/`, а `runtime/`
  используется только после сверки с манифестом: подмена `winws.exe` или
  `TgWsProxy` обычным пользователем больше не даёт обход UAC.
- **sha256-манифест покрывает каждый исполняемый файл и `.bin`.** Проверка
  выполняется при сборке (`verify-dist`) и при каждом старте компонента,
  поэтому подмена одного байта обнаруживается, а необъявленный `.exe` в папке —
  повод отказаться от запуска.
- **Секреты не попадают в логи.** `--secret`, `secret=`, `tg://proxy?...secret=`
  и 32-hex-токены маскируются в единой точке логирования, включая строку спавна
  TgWsProxy: раньше полный ключ уходил в рендерер и файл лога.
- **Завершение только своих процессов.** Процессы ищутся по сохранённому PID и
  владению путём (внутри `resources/`), а kill по имени остался лишь
  fallback'ом с проверкой пути — чужая установка Zapret/TgWs больше не падает.
- **Системные утилиты вызываются по абсолютному пути.** `taskkill`, `icacls`,
  `powershell.exe` и `ipconfig.exe` берутся из `System32`, а `SystemRoot`
  валидируется.
- **Uninstaller чистит только свой блок и свой профиль.** Блок SkipNet в
  `hosts` удаляется при деинсталляции, `C:\Users\*` больше не обходится, а
  junction'ы не разыменовываются — настройки второго пользователя остаются на
  месте.
- **NSIS ставит ACL на `resources/`.** Писать туда могут только Administrators
  и SYSTEM, читать — Users, поэтому payload нельзя подменить до проверки
  хешей.

### Исправлено

- **Страница hosts больше не зависает.** Короткая блокировка состояния
  отделена от длинных DoH/TLS-проб, пробы отменяются при действии пользователя,
  а переключатель отвечает сразу: раньше включение сервиса ждало до 300 с.
- **Тест стратегий не обрывается на одной неудаче и отменяется.** Прогон
  продолжается после ошибки отдельной стратегии, кнопки Start/Stop отвечают во
  время теста, а отмена возвращает прежнюю стратегию.
- **Сбой записи конфига откатывается.** Если запись не удалась, в памяти
  остаётся прежнее значение, поэтому UI больше не показывает «сохранено» при
  фактически потерянных настройках.
- **Второй экземпляр и выход после обновления исправлены.** Single-instance
  завершает процесс до регистрации IPC, а quit/relaunch сначала останавливает
  сервисы — осиротевших `winws.exe` и занятого порта 1443 больше нет.
- **Zapret не залипает после 7-секундного таймаута.** В ветке таймаута процесс
  убивается и ссылка обнуляется, поэтому повторный Start действительно
  запускает обход.
- **Автозапуск экранирует XML и откатывается при ошибке.** Путь установки с `&`
  больше не ломает задачу Task Scheduler, а неудачная регистрация возвращает
  прежнее состояние.
- **Битый `hosts-state.json` восстанавливается по файлу hosts.** Повреждённый
  файл переименовывается в `corrupt-<ts>`, выбор сервисов выводится из
  managed-блока, а не сбрасывается в «всё выключено».
- **Запись `hosts` атомарна.** Temp-файл, `fsync` и `rename` в том же каталоге:
  обрыв питания или падение приложения не оставляет обрезанный файл.
- **Rename повторяется под антивирусом.** `EPERM`, `EACCES` и `EBUSY` дают пять
  повторов; настройки и состояние hosts не теряются, когда AV на секунду держит
  файл.
- **Portable-режим определяется правильно.** 7z-сборка теперь распознаётся по
  отсутствию uninstaller'а и хранит данные рядом с `exe`, а не ставится вторым
  экземпляром в Program Files.
- **Telegram запускается без временного VBS.** Ссылка `tg://` открывается
  напрямую, поэтому защищённые папки и политики не блокируют запуск.
- **Закрытие в трей больше не завершает приложение.** Кнопка «×» скрывает окно,
  а не убивает сервисы; выход остаётся отдельным пунктом меню.
- **Preflight BFE.** Диагностика и запуск проверяют Base Filtering Engine
  заранее и дают понятную ошибку вместо 7-секундного ожидания winws.
- **UTF-16 `hosts` отклоняется с объяснением.** Такой файл не читается
  latin1-пайплайном, и раньше его можно было перезаписать; теперь операция
  отменяется с просьбой сохранить файл в UTF-8.

### Изменено

- **Обновления ставятся по тегу.** Пользователь видит версию и жмёт
  «Установить»: нужный ассет выбирает main-процесс, а не рендерер; ручная
  проверка сохраняет свой результат и переживает рассинхрон тега.
- **Переключатели применяются сразу, фильтрация — по явной проверке.**
  Включение сервиса не ждёт обновления адресов, а «Проверить адреса» остаётся
  явным действием, поэтому UI не выглядит зависшим на медленной сети.
- **Ответы hosts больше не содержат каталог на 226 КБ.** Операции возвращают
  только изменённое состояние, поэтому 107 карточек не перерисовываются на
  каждое переключение.
- **`lint` больше не правит код.** `--fix` вынесен в `lint:fix`, а CI вызывает
  `lint`, поэтому предупреждение валит сборку, а не исчезает молча.
- **Убраны неиспользуемые зависимости и мёртвый код.** Меньше пакетов в сборке
  и меньше поверхности для аудита; дубли `compareVersion`, `broadcast` и
  update-баннера сведены к одному месту.

### Добавлено

- **Vitest: 452 юнит-теста.** Покрыты hosts-render, merge и схема конфига,
  update-integrity, доверие IPC, редакция секретов и restart-локи; тесты не
  требуют admin-прав, сети и реестра.
- **Playwright Electron smoke: 5 сценариев.** Навигация по вкладкам и проверка
  консольных ошибок ловят регрессии, которые юнит-тесты не видят.
- **`BUILD_ID` и генерация манифеста `binaries.sha256`.** Сборка сама
  пересобирает манифест и падает при расхождении, поэтому забытый хеш не
  доедет до релиза.
- **Долговременные JSONL-логи.** `appLog` пишет файл с ротацией и удалением
  старых записей, поэтому сбой можно разобрать после перезапуска, а не только
  по живой консоли.

### Ограничения

- Сборки остаются без подписи кода (политика проекта): SmartScreen может
  предупреждать при первом запуске.
- Portable-ресурсы лежат в user-writable папке, и манифест не защищает от того
  же пользователя, который уже имеет право писать эти файлы.
- Деинсталляция «через плечо» (over-the-shoulder, из-под другого администратора)
  удаляет данные профиля того администратора, который запустил удаление.
- Доверие к компонентам Zapret и TgWsProxy опирается на сторонние
  upstream-репозитории (Flowseal, TgWs): их компрометация — вне модели защиты.
- Удаление блока `hosts` при деинсталляции требует доступного PowerShell.

### Обновление

Настройки, состояние `hosts` и секрет TgWs сохраняются. Первый запуск после
обновления выполняет одну живую проверку обновлений.

## 1.4.0

Живые адреса вместо замороженного каталога: DoH-обновление и проверка TLS.

### Добавлено

- **Кнопка «Обновить адреса»** в шапке редактора и «Подобрать живые» в
  предупреждении. SkipNet опрашивает системный резолвер и три DoH-сервера
  (Google, Cloudflare, AdGuard), собирает кандидатов и проверяет каждый
  реальным TLS-рукопожатием: имя домена передаётся в SNI, сертификат должен
  быть валиден именно для него. В hosts попадают 1–2 самых быстрых
  проверенных адреса — подмена DNS и «мёртвые» пины отсекаются автоматически.
- **Автовозврат сервисов.** Если сервис был выключен из-за недоступных адресов,
  после успешного подбора он включается обратно с прежним DNS-профилем.
  Ручное выключение при этом не отменяется.
- В шапке видно, когда адреса обновлялись и для скольких доменов найдены живые IP.

### Изменено

- Рендер hosts использует проверенные адреса вместо снимка каталога; каталог
  остаётся запасным вариантом для доменов, которые не удалось проверить.
- Предупреждение о пропущенных адресах теперь сразу предлагает подобрать живые.

### Ограничения

- Нужен доступ хотя бы к одному DoH-серверу. Если провайдер режет все три,
  обновление честно сообщит об этом и ничего не сломает.
- Ресурсы, которые блокируются по SNI, через hosts не лечатся: для них нужен
  Zapret. Подбор адресов просто не найдёт для них рабочего варианта.

### Обновление

Настройки и выбранные профили сохраняются. После обновления откройте
«Редактор hosts» и нажмите «Обновить адреса».

## 1.3.2

Исправлена главная причина «интернет и Discord стали медленными» после включения
редактора hosts: каталог писал в hosts адреса, которые уже не отвечают.

### Исправлено

- **Недоступные адреса больше не попадают в hosts.** Перед записью SkipNet проверяет
  каждый IP каталога TCP-подключением на порт 443 (2 с на адрес, 8 параллельно) и
  пропускает мёртвые. Раньше браузер и клиенты сначала шли на неработающий адрес,
  ждали таймаут и только потом пробовали следующий — отсюда «всё грузится по 10–30 с».
  Результаты проверки кешируются: успех — 10 минут, отказ — 2 минуты.
- **Сервис без единого живого адреса выключается автоматически** с понятным
  предупреждением. Если недоступны вообще все адреса (нет сети), настройки не
  меняются — проверка отличает «каталог устарел» от «пропал интернет».
- **Исправлены данные Discord в каталоге.** `hosts.discord` прибивал `discord.com`,

## 1.3.1

Повторный аудит всего проекта: надёжность редактора hosts, миграция и безопасность.

### Исправлено

- **Старые блоки hosts больше не удаляются молча.** Записи ZapretGUI и прежнего блока SkipNet сопоставляются с каталогом по имени хоста, поэтому даже устаревший IP (например, Discord) переносится в сервис. Карточки блокируются до импорта; кнопка «Перенести и применить» вызывается явно.
- **Восстановление из бэкапа согласовано с файлом.** Выбор сервисов заново определяется по содержимому бэкапа, а не по устаревшему sidecar-состоянию. Перед восстановлением текущий файл тоже сохраняется в бэкап; запись проверяется и откатывается при ошибке.
- **Ошибка чтения `hosts` больше не считается пустым файлом.** Если файл существует, но недоступен (антивирус, блокировка), запись отменяется вместо перезаписи всех записей.
- **Сбой записи откатывает исходный файл.** Частично записанный `hosts` восстанавливается из содержимого, прочитанного до операции.
- **Поддержаны комментарии в строке** (`127.0.0.1 localhost # loopback`) при импорте, проверке и восстановлении бэкапов.
- **BOM, CR-only и повреждённые маркеры.** BOM больше не скрывает первый блок, строки с `\r` разбираются, а незакрытые/перевёрнутые маркеры блокируют запись вместо удаления остатка файла.
- **Обновление каталога теперь применяется к файлу:** после загрузки новых адресов появляется баннер «Применить настройки».
- **Выбор DNS-профиля** показывает только профили с адресами для сервиса и недоступен, пока сервис выключен. «DNS для всех» не сбрасывает профили сервисов, для которых в новом профиле нет адресов.
- Состояние нормализует профили без адресов; выключенный сервис больше не может выглядеть включённым без записей.
- Диагностика больше не предупреждает о YouTube-записях, которыми управляет вкладка Hosts.
- Исправлены гонки кнопок: карточки и действия блокируются на время записи, ошибки страницы очищаются после успешной операции.

### Безопасность

- IPC-обработчики принимают вызовы только из главного окна приложения; переходы на сторонние origin и открытие произвольных URL блокируются.
- Каталог проверяет идентификаторы сервисов/профилей и управляющие символы; удалённое обновление может менять только адреса уже известных доменов, но не добавлять новые сервисы/домены.
- Размер скачиваемого каталога ограничивается потоково; временные файлы каталога, состояния и конфига создаются с случайными именами и `wx`.
- UAC-запись `hosts` передаёт PowerShell через `-EncodedCommand` и проверяет SHA-256 временного файла перед копированием; системные `powershell.exe` и `ipconfig.exe` вызываются по абсолютному пути, `SystemRoot` валидируется.
- Восстановление бэкапа проверяет каждую строку и не устанавливает произвольное содержимое.

### Исправлено

- **Zapret больше не остаётся выключенным после обновления.** Если обход был запущен, новый бандл устанавливается и Zapret автоматически запускается снова (если выбранная стратегия есть в новой сборке). То же самое уже работало для TgWsProxy.

- «Перезагрузить процессы» на главной не запускается во время теста стратегий и защищена от двойного клика.
- Результаты теста стратегий от старого бандла больше не применяются к новой сборке (иначе рабочие стратегии могли остаться заблокированными).

- На страницах Telegram и Zapret убрана лишняя кнопка «Назад» — это основные разделы бокового меню.
