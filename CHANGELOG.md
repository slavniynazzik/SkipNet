## 1.3.1

Повторный аудит всего проекта: надёжность редактора hosts, миграция и безопасность.

### Исправлено

- **Старые блоки hosts больше не удаляются молча.** Записи ZapretGUI и прежнего блока SkipNet сопоставляются с каталогом по имени хоста, поэтому даже устаревший IP (например, Discord) переносится в сервис. Карточки блокируются до импорта; кнопка «Перенести и применить» вызывается явно.
- **Восстановление из бэкапа согласовано с файлом.** Выбор сервисов заново определяется по содержимому бэкапа, а не по устаревшему sidecar-состоянию. Перед восстановлением текущий файл тоже сохраняется в бэкап; запись проверяется и откатывается при ошибке.
- **Ошибка чтения `hosts` больше не считается пустым файлом.** Если файл существует, но недоступен (антивирус, блокировка), запись отменяется вместо перезаписи всех записей.
- **Сбой записи откатывает исходный файл.** Частично записанный `hosts` восстанавливается из содержимого, прочитанного до операции.
- **Поддержаны комментарии в строке** (`127.0.0.1 localhost # loopback`) при импорте, проверке и восстановлении бэкапов.
- **BOM, CR-only и повреждённые маркеры.** BOM больше не скрывает первый блок, строки с `\r` разбираются, а незакрытые/перевёрнутые маркеры блокируют запись вместо удаления остатка файла.
- **Обновление каталога теперь применяется к файлу:** после загрузки новых адресов появляется баннер «Применить настройки».
- **Выбор DNS-профиля** показывает только профили с адресами для сервиса и недоступен, пока сервис выключен. «DNS для всех» не сбрасывает профили сервисов, для которых в новом профиле нет адресов.
- Состояние нормализует профили без адресов; выключенный сервис больше не может выглядеть включённым без записей.
- Диагностика больше не предупреждает о YouTube-записях, которыми управляет вкладка Hosts.
- Исправлены гонки кнопок: карточки и действия блокируются на время записи, ошибки страницы очищаются после успешной операции.

### Безопасность

- IPC-обработчики принимают вызовы только из главного окна приложения; переходы на сторонние origin и открытие произвольных URL блокируются.
- Каталог проверяет идентификаторы сервисов/профилей и управляющие символы; удалённое обновление может менять только адреса уже известных доменов, но не добавлять новые сервисы/домены.
- Размер скачиваемого каталога ограничивается потоково; временные файлы каталога, состояния и конфига создаются с случайными именами и `wx`.
- UAC-запись `hosts` передаёт PowerShell через `-EncodedCommand` и проверяет SHA-256 временного файла перед копированием; системные `powershell.exe` и `ipconfig.exe` вызываются по абсолютному пути, `SystemRoot` валидируется.
- Восстановление бэкапа проверяет каждую строку и не устанавливает произвольное содержимое.

## 1.3.0

Новая вкладка «Редактор hosts» с каталогом сервисов и DNS-профилями.

### Новое

- **Вкладка Hosts** управляет системным файлом `hosts` через карточки сервисов, как в ZapretGUI.
- **Каталог из 107 сервисов**: 13 «Напрямую», 20 ИИ-сервисов и 74 остальных — YouTube, Discord, GitHub, WhatsApp, X, Instagram, Telegram, Spotify, JetBrains, Nvidia, Claude, ChatGPT и другие.
- **DNS-профили**: Zapret DNS, XBOX DNS, Comss DNS, AstraCat, GeoHide, DNS-AI. Профиль выбирается для каждого сервиса отдельно или сразу для всех.
- **Готовые адреса из каталога** — IP не нужно резолвить вручную; каталог хранит проверенные ответы для каждого профиля.
- Переключатель на каждой карточке сразу записывает изменения в `hosts`, есть поиск по сервисам и доменам.
- **Импорт блока ZapretGUI**: сервисы распознаются по каталогу, старый блок заменяется блоком SkipNet. Записи Telegram и GitHub из прежнего блока SkipNet также переносятся.
- **Блокировка активации Adobe** — отдельный переключатель, выключен по умолчанию; существующий блок сохраняется при первом открытии.
- **Бэкапы**: перед каждым изменением сохраняется файл `hosts` и состояние выбора; можно восстановить последний бэкап.
- **Сброс DNS-кэша**, открытие файла `hosts`, обновление каталога из репозитория.
- 132 записи Adobe и 35 записей Telegram вынесены в отдельные ресурсы каталога.

### Надёжность и безопасность

- Редактор работает только с системным путём `hosts`; IPC не принимает произвольные пути.
- Каталог проверяется по схеме (домены, IP, профили, размер), скачанный каталог не может подменить локальные данные без валидации.
- Запись атомарная, с UAC-фолбэком, повторной проверкой и автоматическим откатом при расхождении.
- Чужие строки, BOM и кодировка сохраняются байт-в-байт.
- Если в файле найден блок ZapretGUI, изменения блокируются до импорта — старые записи не теряются.
- Управление hosts убрано из «Обслуживания и диагностики»: там осталась ссылка на новую вкладку.

### Важно

- hosts помогает при DNS-блокировках; при DPI/SNI-блокировках нужен Zapret.
- Браузер с Secure DNS может игнорировать `hosts`.

## 1.2.1

Повторный аудит кода: исправления гонок, обновлений и безопасности.

### Исправлено

- **Zapret больше не остаётся выключенным после обновления.** Если обход был запущен, новый бандл устанавливается и Zapret автоматически запускается снова (если выбранная стратегия есть в новой сборке). То же самое уже работало для TgWsProxy.
- **Позднее событие `exit` старого процесса больше не ломает состояние нового.** Раньше, если остановка не успевала за таймаут, «хвост» от предыдущего `winws.exe`/`TgWsProxy` мог обнулить ссылку на только что запущенный процесс и показать ложную ошибку.
- **Установка бандла Zapret корректно останавливает осиротевший `winws.exe`** перед удалением файлов и службы WinDivert, поэтому обновление не падает с `EBUSY` и не рвёт активный обход.
- **Определение состояния службы WinDivert исправлено на локализованной Windows:** `sc query`/`sc qc` теперь разбираются по значениям (`4 RUNNING`, путь `.sys`), а не по английским названиям полей.
- **Проверка прав администратора больше не зависит от службы Server (`LanmanServer`).** На системах, где она отключена, приложение ошибочно завершалось с требованием «запустить от администратора»; теперь используется `fltmc`.
- Поле «Секретный ключ» в Telegram не теряет символы и не сохраняет недопустимое значение: ввод фиксируется по завершении редактирования, ключ проверяется на 32 hex-символа.
- Поля «Хост» и «Секрет» больше не пишут конфиг на каждое нажатие клавиши (раньше конкурентная перезагрузка конфига могла откатывать ввод).
- Кнопки запуска/остановки Telegram и Zapret блокируются на время установки обновления, чтобы не соревноваться с заменой файлов.
- «Перезагрузить процессы» на главной не запускается во время теста стратегий и защищена от двойного клика.
- Результаты теста стратегий от старого бандла больше не применяются к новой сборке (иначе рабочие стратегии могли остаться заблокированными).
- Устаревший ответ проверки обновлений Zapret больше не показывает баннер после отключения автопроверки.
- Выбор стратегии проверяет, что настройка действительно сохранилась, прежде чем запускать обход.
- Обновлена страница «Логи»: `contentClassName` из `BasePage` теперь применяется, а пустой список не передаёт `-1` в Virtuoso.
- На страницах Telegram и Zapret убрана лишняя кнопка «Назад» — это основные разделы бокового меню.
- Исправлена подпись «Убрать иконку с панели задач» (было «Не работает» вместо «Не применяется»).
- Исправлены обои: ползунки прозрачности/размытия/затемнения сохраняются по завершении перетаскивания, а не на каждый пиксель; список Steam Workshop подгружается автоматически для сохранённых обоев.
- Формат файла обоев проверяется по расширению (только изображения и видео) — протокол `skipnet-media://` больше не может отдать произвольный файл.
- Усилена CSP: убраны `img-src *` и `frame-src http://127.0.0.1:*`, добавлены `object-src 'none'`, `base-uri 'none'`, `form-action 'none'`.
- `theme:apply` больше не может выйти за пределы папки тем (защита от чтения произвольных файлов).
- `shell:openTelegramLink` принимает только `tg://` и ссылки `t.me`/`telegram.me`, чтобы не запускать произвольные обработчики протоколов.
- Имя стратегии Zapret проверяется: запускается только `general*.bat` из папки бандла, без путей `..\`.

## 1.2.0

Обои из Steam Workshop и исправления по итогам полного аудита.

### Новое

- **Настройки → Обои**: собственное изображение, видео (без звука, в цикле) или обои из Steam Workshop для Wallpaper Engine.
- Автоматический поиск Steam и всех библиотек, список скачанных элементов Workshop, кнопка открытия страницы элемента.
- Ползунки прозрачности, размытия и затемнения. Видео и изображения из Workshop работают напрямую; для сцен показывается превью.
- В «Обновлениях» появилась настройка автоматической проверки SkipNet и строка с текущей версией приложения.

### Исправлено

- Шаблон конфигурации больше не загрязняется настройками пользователя: `deepMerge` мутировал `defaultConfig`, из-за чего при повреждении конфига восстанавливались чужие/старые значения вместо заводских.
- Обновление списков больше не сбрасывает выбранный режим IPSet («Отключён» / «Все IP»): свежие диапазоны сохраняются в `.backup`.
- Отсутствующий `ipset-all.txt` больше не считается режимом «Все IP».
- Переключатель автоматической проверки обновлений SkipNet теперь реально работает; ручная проверка в настройках тоже показывает окно установки.
- Окно обновления снова появляется при выходе более новой версии после нажатия «Позже».
- Портативная сборка не пытается установить NSIS-версию поверх себя, а подсказывает скачать portable-архив.
- Диагностика не удаляет службу WinDivert, пока запущен winws.exe — это больше не ломает активный обход.
- Если установщик обновления не запустился, Zapret включается обратно, а одноразовый флаг восстановления очищается.
- `check_updates.enabled` синхронизируется с настройкой при каждом запуске и не включается сам после обновления бандла.
- `verify-dist` проверяет наличие `zapret/utils/test zapret.ps1` и `check_updates.enabled`, чтобы регрессия упаковки не повторилась.
- Пути из `project.json` элементов Workshop ограничены папкой элемента (защита от path traversal).

## 1.1.2

Исправления диагностики, hosts и автообновления.

- Диагностика теперь правильно определяет BFE и TCP timestamps на русской Windows: `sc.exe` и `netsh` локализуют названия полей, из-за чего службы и метки времени ошибочно считались отключёнными.
- «Исправить» для TCP timestamps больше не показывает ложную ошибку, если команда выполнилась.
- `zapret/utils` снова входит в установщик: тесты Zapret и переключатель `check_updates.enabled` работают, а папка `utils` создаётся автоматически при необходимости.
- В «Обслуживание и диагностика» → «Файл hosts» добавлена кнопка «Обновить»: программа сама скачивает записи и вписывает их в системный файл. Старый файл сохраняется как `hosts.skipnet-backup`.
- Кнопка карточки «Список хостов и IP» переименована в «Развернуть» / «Свернуть».
- После установки обновления SkipNet снова запускается сам: установщик получает `--force-run`, а резервный наблюдатель проверяет запуск и повторяет попытки.
- Перед обновлением Zapret и Telegram WS останавливаются, чтобы установщик не блокировался занятыми файлами; после перезапуска Zapret включается обратно, если был включён.
